# Data Buffet

A scalable, high-performance web application bridging Indian students with European Data/AI startups.

## Features

- **Job Board**: Curated Data & AI jobs in Europe.
- **Mentorship**: Connect with senior engineers.
- **Admin Dashboard**: Curation tools for admins.

## Tech Stack

- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- Supabase
